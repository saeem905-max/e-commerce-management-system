
# E-Commerce Management System

A console-based E-Commerce Management System built using Core Java.

## Features

- View all products
- Search products by ID
- Add new products
- Update existing products
- Delete products
- Validate product details
- Prevent duplicate product IDs

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList and Collections
- Exception Handling
- Git and GitHub

## Project Structure

- `Main.java` - Handles the menu and user input
- `Product.java` - Represents a product and validates its data
- `ProductService.java` - Handles product-related operations

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure a compatible JDK is installed.
4. Run `Main.java`.

## Current Limitations

- Products are stored in memory using an ArrayList.
- Newly added or updated data is not preserved after restarting the application.
- MySQL database integration is planned for a future version.

## Future Improvements

- MySQL and JDBC integration
- Automated testing
- Spring Boot REST APIs
